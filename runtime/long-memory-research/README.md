조사의 핵심은 저장·회상·정정·격리·삭제를 각각 측정해야 한다는 것이다. Inworld의 현재 가이드는 앱 DB를 통한 복구가 필요하고, 연결된 예제의 기본 검색은 최신 5개 조회다. Convai는 사용자 ID를 공유하면 기억도 공유하며 개별 항목·캐릭터별·사용자 전체 삭제 경로를 구분한다. 각 제품의 내부 구현과 실제 정확도까지 확인한 것은 아니다.

M3는 한국어 합성 자료다. 16기제 × 간판/손님 응대 페르소나 2용도 × 3세션의 96탐침은 서로 관련되므로 96개의 독립 표본이 아니다. 세계 시뮬레이션 NPC 상태는 범위 밖이다. 입력·정답·눈가림 대응표를 분리하며 AI 작성 자료를 사람 라벨로 표시하지 않는다.

현재 계약은 장기 기억 상시 주입 ≤600토큰, T 대화 안 즉시 반영/C 대화 종료 승격, CONTEST 확인형, 기기 쿠키 식별이다. [M4 검토 문서](M4-HARNESS-N-REVIEW-2026-11-16.md)와 [사전등록 계획](eval-v0/plan.json)에 판을 고정했다. 아직 구현하지 않은 인증·link/unlink 동작을 임의의 통과 기준으로 확정하지 않는다.

후속은 오케스트레이터의 관측 어댑터·실제 평가 실행, 리소너의 T/C 연산 채점 연결, 소유자의 삭제 범위 증거 확인이다. [T/C 결합안 검토](M3-OPERATION-JOIN-2026-11-16.md)에 연결 키·지연 작업 시점·정상 연산 예외·눈가림 복원 범위를 정리했다. DBA의 절 N 적용 보고 뒤 [DDL 정적 감사](M4-SECTION-N-DDL-REVIEW-2026-11-16.md)에 쓰기·삭제 경계와 T 직접 저장 제안의 판 변경을 기록했다. C/어댑터와 새 계약판 고정이 후속 조건이다. 임시 저장소나 생략된 원장 필드를 성공으로 채우지 않는다. 평가 자료는 학습에 사용하지 않는다. Comms 인계는 [기록](COMMS-RECORD.md)에 남긴다.
