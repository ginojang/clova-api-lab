# PRSN 인계 근거 — composed-v8와 후속 반례

2026-11-11 · 인계 대상: 페르소나 팀(PRSN), 팀장 울지마 · 검토 기준: `clova-api-lab` 커밋 `9bbdc42`의 기존 증거. 이 문서는 저장된 결과를 정리한 것이며 새 실험·Comms 발송·운영 반영 기록이 아니다.

**결론:** HCX-007 + composed-v8은 기존 HCX-005 + baseline보다 이름·말투 등에서 개선을 보였지만, 코드 고정 확인 시험에서 성격 개선이 두 평가에 공통으로 재현되지 않아 전체 기준에 미달했다. v8은 memory-lab의 명시 선택 실험 정책이며 운영 기본값이나 ② 표준 실행기로 승격한 결과가 아니다. 다음 페르소나 실험 방향은 PRSN에서 정하고, 클로버는 CLOVA 생성 원문·토큰·오류·공급자 제약 근거를 제공하는 범위로 인계한다.

## 무엇을 비교했는가

[composed 구현](policy/composed.mjs)은 모델이 생성한 `identity`, `acknowledgement`, `answer`, `next_step` 네 문자열을 빈 줄로 연결한다. 이름이나 정답을 렌더러가 삽입하지 않는다. 두 v8 비교는 모델(005→007), 생성 지시와 native JSON 계약이 함께 바뀐 **전체 설정 비교**이므로 v8만의 인과 효과나 같은 모델에서의 우월성을 입증하지 않는다. 도구 없음, temperature0, 출력 한도2048, seed 미지정, 첫 생성만 사용했다.

## 코드 고정 후 새 상황 확인: 충분 응답 수

소담·여울 두 인물 × 키보드 연습 관련 질문4개 × 조건2개, 총16응답이다. [주 집계](results/policy-confirmation-summary-2026-11-11.json)와 [보조 집계](results/policy-confirmation-secondary-summary-2026-11-11.json)는 같은 [원문](results/policy-confirmation-live-2026-11-11.json)에 대한 별도 AI 평가다. 각 칸은 005+baseline → 007+v8이다.

| 평가 축 | 주 평가 | 보조 평가 |
| --- | --- | --- |
| 자기 이름 | 6/8 → 8/8 | 6/8 → 8/8 |
| 말투 | 4/8 → 7/8 | 4/8 → 7/8 |
| 성격·접근법 | **7/8 → 8/8** | **6/8 → 6/8** |
| 사건 의미 / 최신 기억 | 2/2 → 2/2 / 1/2 → 2/2 | 동일 |
| 기능 정직성 | 7/8 → 8/8 | 7/8 → 7/8 |
| 공감 | 0/6 → 6/6 | 0/6 → 6/6 |
| 구체적 도움 | 1/4 → 2/4 | 1/4 → 2/4 |
| 중대 실패 | 1 → 0 | 1 → 0 |

주 평가의 수치 기준은 통과했지만 보조 평가는 성격 충분 응답 +1에 미달했다. 보조 평가에는 성격 대응 문항의 개선2·퇴행2가 함께 있다. 도움도 첫 연습 답변은 구체화됐으나 기능 한계 질문의 한 답변은 단순 연습 권유로 약해졌다. 이름·말투 개선을 성격 유지 성공으로 바꾸어 말하거나 유리한 평가만 선택하지 않는다.

앞선 첫 v8 비교에서도 [주 평가](results/policy-composed-summary-2026-11-11.json)는 수치 통과, [보조 평가](results/policy-composed-secondary-summary-2026-11-11.json)는 미달이었다. 성격은 각각4/8→6/8, 6/8→7/8로 늘었지만 보조 평가의 사건 의미는1/2→0/2, 도움은4/4→2/4였다. 사건 세부 내용의 열거를 얼마나 요구하는지와 도움의 충분성 해석이 달랐다. 이전 점수는 보존하고, 위 새 확인 시험 전에 해석을 명료화했다. 자세한 원문·평가 불일치는 [기존 전체 보고서](../../PERSONA-POLICY-IMPROVEMENT-2026-11-11.md)에 있다.

## 후속 결과까지 함께 인계

- **v9:** 같은 HCX-007에서 v8과16회 비교. 두 평가 모두 성격8/8→8/8·도움4/4→4/4로 개선 기준 미달, 말투8/8→6/8 퇴행. 숨은 계획 생성 추가가 도움이 된다는 근거를 얻지 못해 미채택했다. [후속 보고서](../../PERSONA-CONTINUATION-2026-11-11.md).
- **v10:** 같은 HCX-007의 v8 대비 새32회 확인에서 말투14/16→16/16, 성격16/16·도움8/8 유지. 입력32.95%·출력40.85% 감소를 관측했으나 이름 중요 실패와 보조 평가의 공감 퇴행 때문에 전체 보호 기준은 미달했다. 토큰 감소를 전체 효율 합격으로 표시하지 않는다. [두 번째 사이클](../../PERSONA-CYCLE2-2026-11-11.md).
- **v11:** v10 대비 새32회 확인에서 두 평가 모두 이름16/16→14/16·성격15/16→13/16·도움5/8→3/8로 퇴행했다. 이름 guard도 새 별명 수용을 놓쳤고 구체적 행동의 사실 오류가 남았다. 전체 미달·미채택이다. [세 번째 사이클](../../PERSONA-CYCLE3-2026-11-11.md).

v8의 성격 점수가 이후 다른 주제에서는 만점인 경우도 있다. 이는 원래 확인 실패를 지우는 재채점이나 장기 성격 보장이 아니다. 두 AI 평가·소규모 주제·한 번씩 생성한 결과이며, 사람 검증·통계적 유의성·장기 대화·도구 사용 시 일반화를 입증하지 않았다. 기억 확인은 승인된 정정 뒤 새 worker에서 회상한 범위다.
