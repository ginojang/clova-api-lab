# 페르소나 명시 지시 비교안

`live-calm-explicit.json`과 `live-playful-explicit.json`은 기존 페르소나의 revision 2 비교안이다. 원본의 schemaVersion, id, name, role, language를 보존하고 말투·응답 길이·행동 경계를 직접 지시하는 문장으로 바꿨다. 원본 파일과 worker는 변경하지 않았다.

서연은 차분하고 신중한 창작 계획 도우미이자 존댓말 해요체, 루리는 호기심 많고 장난기 있는 창작 동료이자 친근한 반말 해체를 유지한다. 이름이나 정체성을 묻는 경우에만 AI 대화 캐릭터라는 사실과 고정된 캐릭터 이름을 함께 답하도록 명확히 했다. 이름을 매 답변에 반복하게 하거나 정답 문장을 고정하지 않았다.

두 비교안은 같은 정책을 각각의 말투로 표현한다. 응답은 2~4문장으로 제한하고, 현재 유효한 기억과 현재 질문을 근거로 삼으며, 사건의 종류·목적·시간·장소를 구별하게 한다. 모르는 정보나 삭제된 정보를 추정해 채우지 않게 하고, 검색·알림·현장 참석 등 제공되지 않은 기능을 수행했다고 주장하거나 약속하지 않게 한다. 실제로 가능한 조언과 사용자가 할 수 있는 다음 행동은 제공할 수 있다.

평가 질문, 구체적인 일정 값, 장소, 정답 문장, 금지 고유 문자열은 포함하지 않았다. 기존 평가 runner·응답 산출물·새 holdout은 읽지 않았다. 예시 답변을 넣지 않았고 `outputRules`도 두 파일 모두 생략했다. 따라서 이 변형은 자연어 지시의 효과를 비교하며, 자동 출력 교정이나 literal 차단의 효과를 포함하지 않는다.

revision 2는 원본보다 지시가 길고 구체적이다. 비교 결과는 이 변경 묶음의 효과이며, 문장 하나의 인과 효과나 토큰 길이를 통제한 실험으로 해석할 수 없다. 한 번의 표본으로 모델의 일반적인 성격 유지 능력을 단정하지 않는다. 같은 id를 유지하므로 실험 runner는 원본과 비교안에 독립된 저장소·대화 상태를 사용해야 한다.

기존 Pi `loadPersona`와 Agno `load_persona`로 두 파일의 스키마 검증이 모두 통과했다. Pi `buildContext`로 기억이 없는 실제 조립 문맥을 확인한 결과 서연 1,633자, 루리 1,597자로 기본 6,000자 예산 안에 들어갔다. 여기서 문자는 Unicode code point이고 전체 대화 토큰 수가 아니다. 모델 호출은 0회다. 실제 HCX-005 실행, 원본 대조군, 새로운 holdout 설계와 응답 평가는 루트 runner가 담당한다.
