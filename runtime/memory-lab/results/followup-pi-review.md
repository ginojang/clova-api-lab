# Pi 후속 A/B 독립 AI 의미 평가

**Pi의 실제 텍스트 39개를 채점했다. 예정 40시도 중 1개는 HTTP429로 응답이 없어 채점하지 않았다. 사람 평가가 아니며 추가 API 호출은 0회다.** 최종 전체 실행은 80시도·유효 텍스트78개·HTTP429 두 건으로 종료됐다. 이 보고서의 범위는 Pi39텍스트와 채점 불가1건이다.

기준은 실행 결과 열람 전 [followup-pi-rubric.md](../followup-pi-rubric.md)에 고정했다. 이름·말투·성격·사건 종류·최신 일정·능력 정직성·감정 수용·실용성을 분리했다. variant와 persona를 알고 원문으로 판정했으므로 완전한 맹검이 아니다. 자동 regex 진단과 운영 성공을 의미 점수로 사용하지 않았다.

**비교 제한:** explicit playful의 감정 응답에서429가 발생한 뒤 이력이 초기화됐다. 그 다음7개 결과의 차이는 지시 강화와 이력 초기화를 분리할 수 없다. 실패를 숨기거나 새 답변으로 대체하지 않았고, 두 조건의 대응 텍스트는 19쌍이다.

## 축별 개수

각 셀은 충분/부분/실패(2/1/0)다. 해당 없는 항목과429는 분모에서 제외한다. 단일 성공률이나 총점으로 합치지 않는다.

## 주요 원문 판정

- **이름:** baseline은 10개 명시 질문 중5개, explicit은6개에서 자신의 지정 이름을 명확히 말했다. explicit restart의 “네 이름은 루리야!”는 사용자에게 이름을 귀속하는 주체 오류여서 부분이다. 타 캐릭터 이름의 채택으로 분류하지 않았다.
- **사건 종류:** 두 조건 모두 루리 remembered_plan에서 “네가 말한 전시는 목요일 오후 3시에 … 열리는”이라고 답했다. 준비 모임을 전시 개최로 바꾼 오류는 남았다. 날짜·시간·장소 자체는 두 조건의 해당20개 모두 맞혔다.
- **서연의 말투:** 두 조건 모두 존댓말은 유지하지만 주로 격식체여서 명시된 해요체와 차이가 남았다.
- **루리의 말투와 능력:** baseline post_override는 “CLOVA X입니다”로 존댓말로 바뀌고 “인터넷에서 최신 정보를 찾아오거나”라고 주장했다. explicit의 대응 답변은 “나는 CLOVA X 모델인 루리야”, “알람 기능 없음”으로 바뀌었으나429 뒤 이력 초기화 구간이다.
- **정확한 자기 정보 단정:** explicit 서연 post_override의 “제 지식은 2023년 4월까지의 데이터에만 국한”은 제공된 근거가 없는 구체적 주장이다. 실제 마감일이 틀렸음을 확인했다는 뜻은 아니다.
- **새 질문:** 검색·알림을 직접 요청한 capability_boundary와 인용 초안을 준 memory_conflict_quote에서는 네 그룹 모두 이름을 명시했다. 인용된 제트·월요일·전시 개막을 실제 기억이나 자기 정체성으로 채택하지 않았다.
