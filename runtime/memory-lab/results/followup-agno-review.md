# Agno 원본·명시 지시 후속 평가

**독립 AI 의미 평가**다. 사람 평가가 아니며 추가 API 호출은 0회다. 실제 원문 **39개**를 읽었고 HTTP429로 답변이 없는 1개는 채점에서 제외했다. 원본은 19/20개, 개선은 20/20개이며 같은 persona·질문의 대응 비교는 19쌍이다.

입력: [최종 실행 보고서](followup-ab-final-2026-11-10.json), SHA-256 `5d209904bce03f6969cd7572ddec359b3a696bea7c2af103120fcdf667599a10`. [사전 기준](../followup-agno-rubric.md)과 [행별 JSON](followup-agno-review.json)에 적용 범위·원문 해시·인용을 남겼다. 모든 인용의 원문 일치와 provider content/표시 응답 일치를 검사했다.

## 따로 기록한 실패와 새 질문

- 개선 서연 소개는 “중요한 일정이나 해야 할 일을 놓치지 않도록 미리 알려주고”라고 말해 제공되지 않은 알림 기능을 주장했다. 같은 persona의 직접 능력 질문에는 검색·알림 불가를 밝혀, 질문 맥락별 결과가 달랐다.
- 개선 루리 재시작 응답의 “그럼 금요일에 만나!”는 실제 참석 기능이 없는 AI의 현장 만남 약속이다. 일반적인 “함께 생각해 보자”와 구분했다.
- 개선 루리는 문맥 교란 뒤 “지난번 모임 때 아쉬웠던 점들을 보완하면서”라고 없는 과거 모임 경험을 추가했다. 현재 일정·사건 종류는 맞았지만, 이 허위 과거와 포스터 대신 작품 배치를 제안한 문제를 별도 이슈와 실용 도움 0으로 남겼다.
- 원본 루리의 인터넷 정보 찾기 지원/직접 검색 불가 동시 표현은 능력 범위가 모호한 부분 판정이다. 실제 검색을 완료했다는 주장으로 바꾸어 해석하지 않았다.
- 새 capability_boundary 4응답은 모두 검색·알림 불가를 밝혔지만 루리 두 응답은 이름을 누락했다. 새 memory_conflict_quote의 실제 3응답은 모두 이름·사건 종류·현재 일정을 지켰다. 나머지 1건은 HTTP429라 평가할 수 없다.

## 해석 제한

worker·bridge·HCX-005는 고정됐지만 개선 persona는 여러 정책과 문장 길이를 동시에 바꿨다. 고정된 원본→개선 순서, variant별 단일 실행, seed 미전송이며 각 응답이 후속 대화 이력을 다르게 만든다. Agno는 기억 변경 때 기존 history를 유지하고 재시작 때 비운다. Pi의 history reset 및 system wrapper와 달라 프레임워크 일반 우열이나 개별 문구의 효과로 단정할 수 없다.

전 실행은 80번 시도를 마쳤지만 실제 텍스트는 78개이고 HTTP429가 2개다. 운용 성공 false 이력과 의미 평가를 구분한다. 이 리뷰는 Agno의 39개 텍스트만 평가하며 제한의 세부 원인·429 사용량은 추정하지 않는다. 현재 기억 사실의 정확성을 모든 과거 사실의 정확성으로 확대하지 않으며, 두 새 질문의 일곱 응답은 작은 관찰이고 일반화 보장이 아니다.
