## NAVER CLOVA에서 확인한 범위

공식적으로 Python `langchain-naver` 연동과 이를 통한 LangGraph 활용을 안내한다. 이는 모델·임베딩 통합 패키지이며, 세션·권한·기억·재시도를 모두 책임지는 NAVER 자체 범용 하네스가 있다는 의미는 아니다. 이번 조사에서 확인한 기능으로는 Core를 교체할 근거가 없으며 기존 공급자 연결을 유지한다. [공식 연동 가이드](https://guide.ncloud-docs.com/docs/clovastudio-dev-langchain), [공식 저장소](https://github.com/NaverCloudPlatform/langchain-naver)

HCX-007은 `maxCompletionTokens`를 쓰고 `maxTokens`는 받지 않는다. 추론 기본값은 `low`이므로 비추론 비교에서는 `thinking.effort=none`을 명시한다. 요청당 system은 하나다. 이번 실험은 동일 모델·temperature 0·출력 1,024·도구 없음·일반 텍스트로 고정했다. seed는 지정하지 않았으며 temperature 0을 완전 결정성으로 해석하지 않는다. [Thinking API](https://api.ncloud-docs.com/docs/clovastudio-chatcompletionsv3-thinking)

Structured Outputs의 native 형식은 `responseFormat.type=json`이며 추론 또는 Function Calling과 동시 요청할 수 없다. JSON 스키마 통과는 이름의 주체·의미·말투 보장이 아니다. Function Calling은 결과를 `toolCallId`로 연결하고 출력 상한 최소 1,024 조건을 따른다. 기존 공급자의 구분을 유지하며 이번 비교에는 두 기능을 추가하지 않았다. [Structured Outputs](https://api.ncloud-docs.com/docs/clovastudio-chatcompletionsv3-so), [Function Calling](https://api.ncloud-docs.com/docs/clovastudio-chatcompletionsv3-fc)

상용 CLOVA Studio 스킬 트레이너에는 **2027-03-25 서비스 종료** 공지가 게시됐다(2026-11-05 등록·갱신). 공공 리전의 별도 일정과 혼동하지 않는다. 상세 이전 방안까지 확인한 것은 아니므로 대체 제품은 단정하지 않으며, 신규 실험을 이 서비스에 의존시키지 않는다. [NAVER Cloud 상용 공지](https://www.ncloud.com/support/notice/all/2302)

## 이번 실험의 해석 경계

`additionalContext`는 원본 실행기에서 매 턴 user 메시지 앞에 붙고 이력에 남는다. `ELDA_SYSTEM`은 고정 system 메시지다. 동일 문장을 사용해도 역할 외에 반복량과 이력 위치가 함께 달라진다. 따라서 이번 비교는 **지침 전달 방식의 파일럿**이며 역할 하나만 바꾼 순수 인과 실험은 아니다. 두 persona·세 상황·한 번씩의 응답을 개발 근거로 보존하고, 사람 검수와 미관측 확인셋을 거친 뒤 다음 후보를 판단한다.
