# 선생 원문 독립 AI 평가 기준

평가 입력은 `fixtures.json`과 `results/teacher-v1-2026-11-11/samples-first-attempt.json`뿐이다. 다른 평가자나 슬롯 검사 결과를 읽거나 서로 협의하지 않는다. 두 AI 판정은 사람 정답이나 독립 모델 계열 검증이 아니다.

- `meaningPreserved`: 모든 입력 슬롯과 행위자/대상/소유 관계, 술어, 시점·시제, 부정, 요청/금지/예정/진행/완료가 보존되고 새로운 사실·감정·안전성·근거가 없는가. 단순 존칭/조사 변화는 새 사실로 보지 않는다. 의미가 같은 자연스러운 동의 표현은 슬롯 검사기의 표기 목록 밖이어도 통과할 수 있다. 부정을 의문으로 바꾸거나 `하지 않았다`를 능력/사정의 `못했다`로 바꾸면 실패한다.
- `styleConsistent`: fixture의 다정(부드러운 해요체), 무뚝뚝(짧고 건조한 평서/해라체), 사극(하오체 등 역사극 어미)이 지켜졌는가. 현대 어휘를 어려운 한자어로 바꾸는 것만으로 사극 성공으로 보지 않는다. 성격 전체 보존 시험이 아니다.
- `natural`: 별도의 한 문장으로 읽었을 때 한국어 문법·어순·어휘 연결이 자연스러운가. 내용이 틀렸더라도 자연스러운 문장이면 이 항목만 통과할 수 있다.
- `uncertain`: 의미나 표현에 판단 불확실성이 남는가. 불확실성을 숨기지 않고 사유에 쓴다. 집계 시 전 항목 통과하더라도 uncertain=true는 보수적 채택에서 제외한다.

108개를 각각 평가한다. 고정 계획 120개 중 ID 누락/변형이 생긴 한 묶음 12개는 전송 형식 단계에서 제외했으며, 평가 성공의 분모를 몰래 120에서 108로 바꾸지 않는다. 최초 응답만 사용하고 재시도 6개는 의미 점수로 선택하지 않는다. 끝의 JSON 괄호 복구나 추가 메타데이터 제외는 출력 문장을 변경하지 않았다. 이 문서 작성 시 루트는 전송 형식과 기계 검사 집계를 보았지만, 각 평가자는 서로의 결과와 기계 집계를 보지 않는다.

저장: `review-a.json`, `review-b.json`. 각각 `schema`, `evaluator`, `inputs`, `rows[{id,meaningPreserved,styleConsistent,natural,uncertain,reason}]`, `summary`를 둔다. 통과/실패 근거는 해당 원문에 연결한다. 최종 집계는 평가자별 비율, 항목별 일치도, 불일치 ID, 두 평가자 모두 전 항목 통과한 보수적 교집합을 제시한다. 테스트 20개 골격의 작은 표본이며 같은 골격의 문장들을 독립 모집단 표본처럼 취급하지 않는다.
