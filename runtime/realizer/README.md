# 초소형 한국어 문장 다듬기망 — 한 쪽 결론

2026-11-11. 풀스택 Comms `8b674818d0` 요청의 조사·소규모 검증을 완료했다. **확정된 게임 대사의 표현 단계에 한정하면 개발할 근거가 있다. 현재 공개 체크포인트를 그대로 넣어 기존 decode 전체를 대체하거나, 10~50MB·수십 ms를 달성했다는 결론은 낼 수 없다.** 학습·운영 반영은 하지 않았다.

실제 오케스트레이터의 decode는 질문·RAG·이력·도구 결과를 받아 내용 선택도 한다. 먼저 상위 로직이 행위자·대상·수치·시제·부정·요청/완료를 확정한 의미 계획을 만들어야 한다. 작은 모델은 그 계획의 표현을 맡고, 문장 전체를 검사한 뒤 전송하는 경계가 필요하다. 현재 SSE는 검사 전에 토큰을 보내므로 단순 모델명 교체만으로 이 경계가 생기지 않는다. [소스 분석과 연결 설계](research-control-training.md)

CPU 실측은 AVX2 없는 **pluto Xeon E5-2640**, 5 warmup+10 samples, 고정16/32 생성토큰의 비용이다. 작은 모델의 한국어 문장 품질이나 자연 종료 문장 길이를 입증하지 않는다. 실제 묶음은 encoder/decoder/cached-decoder **3개 그래프와 tokenizer/config**이며 공유 가중치 중복과 FP32 embedding이 남는다. 최소 가능한 배포량은 아니다. [CPU 원시 수치·재현](BENCHMARK-CPU.md), [선생 원문·두 평가·호출 집계](TEACHER-RESULT.md)

**추천 순서:** 승인된 틀 문장을 기준으로 삼고, KE-T5를 한국어 학습 비교 기준으로 둔다. 목표 크기의 학생은 약 **23M, tied embedding, 16k 어휘, 구조 슬롯 placeholder**를 우선 실험안으로 제안한다. 이름·숫자는 프로그램이 복원하고 조사·어미·어순을 모델이 담당한다. 슬롯 존재만으로 의미역이 보장되지는 않으므로 부정·소유·요청/완료 검사와 fallback을 함께 비교한다. 1k~5k 검수 쌍으로 데이터 경로를 점검한 뒤 20k→100k learning curve를 제안하며, GPU 시간은 측정 전 가정값만 적었다. **학생 학습은 실행하지 않았다.** [제어 연구·데이터·학습 계획](research-control-training.md)

**다음 선생은 이번 HCX-005 구성을 채택하지 않고 더 강한 후보를 비교 검증해 선정한다.** 특정 다른 모델의 우월성을 이번에 검증한 것은 아니다. 풀스택 회신 `4e41430159`에 따라 이 갈래는 조사 완료 후 보류하며, 학습의 GPU 자리·시점은 사용자가 결정할 때 다시 연다.

외부 근거도 목표의 일부만 지지한다. 영어 WebNLG의 **10.6M LSTM** 사례는 작은 구조→문장 모델의 가능성을 보여주지만 한국어 말투 품질의 증거는 아니다. 공개 한국어 후보는 어휘 행렬이 전체의 약19~54%를 차지한다. pko-T5-small은 카드77M와 설정 계산95.63M가 다르며 라이선스 표시도 충돌한다. 후보별 출처·크기·상용 조건·실제 공개 int8 파일을 분리했다. [모델·선행연구 표](research-models.md), [10.6M 원논문](https://aclanthology.org/2020.emnlp-main.577/)

수치 정정: **BGE-M3는 250,002×1,024=256,002,048 embedding parameters**다. 0.1B의 가중치만 계산하면 FP32/FP16/INT8/4bit는400/200/100/50MB지만 실행 파일·메모리와 같지 않다. Transformers.js/ORT Web의 T5·BART 경로가 있어도 CPU용 동적 INT8 그래프가 WebGPU에서 그대로 가속된다고 볼 수 없다. 2026 브라우저 지원·OS/GPU 제약을 조사했으며 **WebGPU/WASM·모바일 지연은 직접 측정하지 않았다.** [런타임·브라우저·수치 검증](research-runtime.md), [BGE-M3 공식 설정](https://huggingface.co/BAAI/bge-m3/blob/main/config.json)
